# T-002 — Configuração administrativa Firebase

ID: T-002
Título: Preparar projeto Firebase para autenticação e hospedagem
Objetivo: Configurar os recursos Firebase que pertencem à conta do usuário para permitir autenticação real e hospedar Red Jacket.
Escopo: Selecionar/criar projeto, confirmar plano e região quando aplicáveis, provedor de autenticação, domínios autorizados e política de usuários conforme decisão explícita do usuário.
Fora de escopo: Implementar login no código, publicar/deploy, definir regras de acesso a dados sem política aprovada.
Critérios de aceitação: Projeto/titularidade identificados; plano e possíveis custos, provedor, cadastro, domínios e políticas explicitamente aprovados; nenhuma credencial exposta; configuração verificada.
Dependências: T-000 aprovado e decisões/aprovação do usuário.
Arquivos/áreas: Firebase Console por autorização explícita; sem segredos no repositório.
Testes exigidos: Testes em ambiente de desenvolvimento/emulador e revisão independente da configuração.
Prioridade: P1
Dificuldade: Difícil
Status: Bloqueada; escolhas administrativas pendentes do usuário.
