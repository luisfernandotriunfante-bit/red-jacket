# T-003 — Configuração administrativa Firebase

ID: T-003
Título: Preparar projeto Firebase para autenticação e hospedagem
Objetivo: Configurar os recursos de conta Firebase necessários para permitir autenticação real e hospedagem do Red Jacket.
Escopo: Selecionar/criar projeto, plano e região/ambiente quando aplicáveis, provedor de autenticação, domínios autorizados e política de usuários conforme decisão do usuário.
Fora de escopo: Implementar login no código, publicar/deploy, configurar regras de acesso a dados sem política aprovada.
Critérios de aceitação: Projeto e titularidade identificados; plano/custos, provedor, cadastro, domínios e políticas explicitamente aprovados; credenciais não expostas; configuração verificada.
Dependências: T-000 aprovado; decisões e aprovação do usuário.
Arquivos/áreas: Firebase Console, somente com autorização explícita para ações administrativas; nenhum segredo no repositório.
Testes exigidos: Teste em ambiente de desenvolvimento/emulador e revisão independente da configuração.
Prioridade: P1
Dificuldade: Difícil
Status: Bloqueada; escolhas administrativas pendentes do usuário.
